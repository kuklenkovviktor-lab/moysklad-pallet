# Приёмка палет МойСклад

Прототип: один скан штрихкода упаковки → приложение находит упаковку товара в МойСклад → берет `pack.quantity` → добавляет это количество в документ Приёмка.

Пример:
`2000000000404` → `1240_CRYSTAL_NONE` → упаковка `Палета` → `144` → в Приёмку добавляется `144` базовых единиц.

## Установка

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
```

## Запуск

Windows PowerShell:

```powershell
$env:MOYSKLAD_TOKEN="ТВОЙ_ТОКЕН"
$env:MOYSKLAD_RECEIPT_ID="UUID_ПРИЕМКИ"
python app.py
```

Открыть на компьютере:

`http://127.0.0.1:5000`

С телефона в той же Wi‑Fi сети:

`http://IP_КОМПЬЮТЕРА:5000`

Bluetooth/USB-сканер должен работать как клавиатура и отправлять Enter.

## Что делает код

1. Получает штрихкод палеты.
2. Ищет его среди `packs[].barcode` товаров.
3. Берёт `packs[].quantity`.
4. Находит товар в текущей Приёмке.
5. Если товар уже есть — увеличивает `quantity`.
6. Если товара нет — создаёт позицию.
7. Показывает подтверждение на экране.

## Важно

- API-токен не хранится в коде.
- Первый тест делай только на тестовой Приёмке.
- Прототип листает каталог по 1000 товаров. Для боевой версии лучше локальный кэш.
- Перед боевым запуском надо отдельно проверить цену/НДС и права API на вашем аккаунте.

## Изолированный запуск на собственном VPS

Docker Compose с отдельной PostgreSQL, генерацией тестовых секретов и резервным
копированием: [инструкция HOSTKEY](docs/HOSTKEY_DEPLOYMENT.md).
Рабочий Render, производственные данные и DNS эта конфигурация не изменяет.

Обновление backup для Yandex Object Storage и Telegram:
[ручная инструкция без изменения app/db](docs/HOSTKEY_BACKUP_UPDATE.md).
