# ONIX: второй Xprinter XP-460B (USB) — безопасный первый тест

Это **только локальная проверка USB-печати в Windows**. Пока здесь **нет**
связи с Render / ONIX, оригинальных стикеров Wildberries, заказов сборки или
автоматической очереди. Код запускается вручную и без параметра
`--send-one-test` ничего не печатает.

## Подготовка

1. Подключи второй XP-460B по USB, установи драйвер и в Windows
   «Принтеры и сканеры» убедись, что видны **два отдельных принтера**.
2. Переименуй **только тестовую очередь** точно в `ONIX-TEST-XP460B`.
   Рабочую очередь с FBS не переименовывай. Если устройства одинаковые,
   проверь идентичность очереди, временно отключив **только второй USB-кабель**
   и убедившись, что отключается именно `ONIX-TEST-XP460B`.
3. Выбери рабочий FBS-принтер как принтер **по умолчанию**. Проверочный скрипт
   откажется печатать на принтере по умолчанию.
4. В тестовый XP-460B установи рулон этикеток **40×30 мм**. Укажи в
   драйвере такую же геометрию. Если фактический зазор не 2 мм, скорректируй
   параметр `GAP` в `onix_usb_print_test.py` **перед** пробой.
5. Установи Python на Windows и затем в PowerShell в папке проекта:
   `py -m pip install pywin32`.

## Проверка

```powershell
py onix_usb_print_test.py --list
py onix_usb_print_test.py --printer ONIX-TEST-XP460B
```

Обе команды только проверяют список устройств. **Никакой печати нет.**

Для **одной** диагностической этикетки:

```powershell
py onix_usb_print_test.py --printer ONIX-TEST-XP460B --send-one-test
```

На этикетке должно быть написано **ONIX TEST / NOT WB**, рядом QR
`ONIX-TEST-ONLY`. Это **не настоящий стикер WB**, и его нельзя наклеивать
на заказ. Проверь геометрию, читаемость QR, отсутствие смещения и что рабочий
FBS-принтер не напечатал ничего лишнего. Команда отправляет данные TSPL RAW,
а не PDF; принтер и его прошивка должны поддерживать TSPL.

Отправка задания в очередь Windows **не подтверждает физической печати**.
Если очередь зависла, проверь её в Windows; не повторяй команду автоматически.

## Следующий этап (ещё не реализован)

После проверки оборудования предстоят: сохранение исходных WB-страниц PDF
с проверкой соответствия заказу, менеджерское подтверждение партионной печати,
очередь заданий ONIX, авторизованный локальный агент, привязка принтера к
линиям склада, защита от дублей и подтверждение печати. Не подключай
автоматическую печать живых заказов, пока эти проверки не готовы.
