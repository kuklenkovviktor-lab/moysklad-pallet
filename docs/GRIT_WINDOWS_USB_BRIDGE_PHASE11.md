# GRIT WMS: approved synthetic queue -> Windows XP-460B bridge

Date: 2026-11-26. Parent draft PR #207, issue #192.
**Disposable synthetic prototype ONLY. No production API, WB orders, real WB stickers, production database or rollout.**

## Prior confirmed result

PR #207: 16 fake-spooler tests passed. A separate permitted Windows test printer ONIX-TEST-XP460B on USB005 printed one synthetic GRIT label; user photo confirms physical output and user confirmed QR scanned. Installed stock was NOT 58x40, so exact fit on 58x40 remains unverified.

## New end-to-end protocol

1. An authorized GRIT demo manager chooses a synthetic printer with a queued invented order and clicks the Windows-agent approval button. Only ONE active approval exists at a time. Approval alone does NOT print, dispatch, or change the job state.
2. A separate Windows program, manually invoked, checks the dedicated non-default ONIX-TEST-XP460B USB queue and authenticated localhost SSH tunnel at 127.0.0.1:18769.
3. After exact manual confirmation, the Windows agent obtains ONE approved ticket. The server locks and revalidates order/catalog/routing, moves QUEUED -> SENDING and audits. A crash after claim never automatically returns the job to the queue.
4. The agent constructs a fixed test TSPL label LOCALLY, containing no real WB sticker or original sticker text. Printed test QR: GRIT-DEMO- plus the ticket's first 16 lowercase hex characters.
5. The agent creates a unique attempt journal in LOCALAPPDATA/GRIT-WMS/USB-Bridge before touching the Windows spooler. Only one RAW submission. No automatic retry. A spooler ACK changes SENDING -> SUBMITTED, never PRINTED; an uncertain result becomes UNKNOWN or stays SENDING awaiting investigation.

## Gates and safeguards

- Only GRIT_SYNTHETIC_PG_TEST=YES_ISOLATED with verified grit_pr192_synthetic_* PostgreSQL database.
- Fresh separate device token GRIT_PR192_USB_AGENT_TOKEN generated by isolated demo runner, NOT WB, GRIT production or GitHub token.
- Server-side manager session + CSRF required for approval; device token required for claim/status reporting; agent cannot choose job IDs or printer targets from the response.
- Agent network endpoints fixed to http://127.0.0.1:18769 via operator-created SSH local forward; no public port, redirect or proxy.
- Only dedicated local USB printer ONIX-TEST-XP460B, never default Windows printer.
- Journal is permanent per ticket; do not delete it or reprint after ambiguous outcome.
- No background daemon, no automatic polling and no auto retry in this PR.
