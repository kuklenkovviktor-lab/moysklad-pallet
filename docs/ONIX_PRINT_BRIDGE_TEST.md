# ONIX → USB Xprinter: облачный тест печати

**Статус:** первый безопасный мост для **тестовой**, не WB, этикетки.
Ранее проверена физическая печать с компьютера на второй XP-460B.
Рабочая программа FBS и реальные стикеры WB этим мостом не используются.

## Что нужно подготовить

- Тестовый USB-принтер в Windows называется строго `ONIX-TEST-XP460B`.
- Рабочий Xprinter назначен принтером Windows по умолчанию.
- Печать локальной проверки `py onix_usb_print_test.py --printer ONIX-TEST-XP460B --send-one-test` уже подтверждена.
- На ПК установлены Python 3.15 и `pywin32`; для агента дополнительных библиотек не нужно.

## Шаг 1. Создай отдельный ключ в Windows (не отправляй его в чат!)

В CMD:

```cmd
py -c "import secrets; print(secrets.token_urlsafe(40))"
```

Сохрани полученное значение в безопасном месте. Не публикуй его в переписке, на скриншотах и в GitHub.

## Шаг 2. Настрой Render

В **основном Frankfurt-сервисе** ONIX добавь переменную среды
`ONIX_PRINT_AGENT_TOKEN` со значением, которое создал на компьютере.
После изменения Render запустит новый деплой. Старый рабочий принтер
при этом никак не меняется. Не нужно добавлять секрет в GitHub
или вставлять его в `.py` файл.

Если переменная не задана, API безопасно остаётся отключённым.

## Шаг 3. Создай тестовую задачу в ONIX

Открой в браузере, где уже вошёл как менеджер:
`https://onix-wms-frankfurt.onrender.com/manager/onix-print-test`

Нажми **«Создать одно тестовое задание»**. Это не печатает автоматически:
статус станет `queued`.

## Шаг 4. Один раз запусти агент на ПК

Скачай `onix_print_agent.py` и `onix_usb_print_test.py` в одну папку
(`Downloads`). В этой папке открой CMD и введи:

```cmd
py onix_print_agent.py --once
```

Когда появится запрос, введи ключ. Символы ввода не отображаются.
Агент проверяет принтер, получает **максимум одно** задание по HTTPS,
печатает **только фиксированную этикетку ONIX TEST / NOT WB** и пытается
записать статус обратно в ONIX. Он не работает постоянно, не
распечатывает ничего сам по расписанию и **не повторяет** задание.

## Проверка

- В Windows печатает только `ONIX-TEST-XP460B`.
- В ONIX статус `submitted` означает **принято очередью Windows**, а
  не «физически распечатано». Факт печати оператор проверяет вручную.
- `claimed` или `uncertain`: не запускай печать снова. Сначала
  проверь очередь Windows и сверь статус вручную. Автоповтора нет.
- QR `ONIX-TEST-ONLY` не имеет отношения к заказам Wildberries.

Это ещё не production-print-agent. Перед печатью WB нужен отдельный
этап разработки с сохранением оригинальных PDF-страниц, проверкой
соответствия заказам и защитой выдачи между сотрудниками.
