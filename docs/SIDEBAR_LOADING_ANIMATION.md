# Анимация боковой панели GRIT WMS

Этот PR подготавливает замену статичной иллюстрации `.sidebar-art` на зацикленную анимацию погрузки коробок. Изменяются только менеджерский UI, локальный статический endpoint и CSS, без изменения бизнес-логики и базы.

**Бинарный GIF необходимо добавить отдельным коммитом в корень репозитория под точным именем `grit-sidebar-loading.gif`. Пока его нет, приложение корректно показывает прежний SVG.** Исходный GIF пользователь получил в чате ChatGPT, файл можно сохранить как `grit-sidebar-loading.gif`.

Требования к GIF: 12 кадров, 306×413 px, работник берёт коробку с палеты, несёт к грузовику, ставит, возвращается; рохля не должна исчезать/прыгать.

Проверить перед слиянием:
- `GET /grit-sidebar-loading.gif` возвращает `200`, `Content-Type: image/gif`;
- GIF играет только в левой нижней части менеджерской панели, не перекрывает кнопки;
- `prefers-reduced-motion: reduce` показывает прежнее статическое SVG;
- при отсутствии GIF запрос отдаёт `404`, а CSS оставляет статическую картинку;
- проверить визуально производительность sidebar в Chrome/Edge и на низкой высоте экрана.

**Не запускать production deploy до проверки бэкапов и безопасности CI/CD.**
