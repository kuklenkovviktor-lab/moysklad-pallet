# GRIT: приватная синхронизация Google Sheets, только чтение

Источник: **собственная таблица владельца GRIT**, листы `Габариты` (A:E) и
`Сводный` (A:B начиная с третьей строки). Эти данные используются
**только** для виртуальной лаборатории планирования Ozon FBO.
Рабочие сканы, заказы, остатки и назначения ячеек не меняются.

## Однократная настройка на личном HOSTKEY VPS

1. В личном проекте Google Cloud включить **Google Sheets API** и создать
   отдельный **service account** для GRIT. Выдать ему минимальные права:
   к самой таблице **Читатель (Viewer)**, никаких прав редактора.
2. Открыть Google-таблицу, «Настройки доступа / Поделиться», добавить
   `client_email` сервисного аккаунта с правами **Читатель**.
   Таблицу **не делать публичной**.
3. На личном домашнем компьютере создать JSON-ключ только для этого
   аккаунта (если администратор Google Cloud разрешает выпуск ключей).
   В приватных настройках сервера/деплоя (не в GitHub-репозитории и не в
   сообщениях чата) добавить переменные:
   - `GRIT_GOOGLE_SPREADSHEET_ID`: идентификатор этой Google-таблицы
     из URL (только ID, не полный URL).
   - `GRIT_GOOGLE_SERVICE_ACCOUNT_JSON`: полное содержимое JSON
     service-account-ключа, **одной переменной**, без изменения
     переносов строк внутри JSON.
4. Обеспечить передачу этих переменных контейнеру веб-приложения GRIT
   и перезапуск процесса. Не печатать содержимое переменных в логах.
5. Открыть в панели менеджера «Ozon FBO → Лаборатория маршрута».
   Вверху есть «Синхронизировать Google Sheets». Статус показывает
   количество артикулов с габаритами и время обновления.

## Поведение и безопасность

- Система читает только Google Sheets API, OAuth scope
  `https://www.googleapis.com/auth/spreadsheets.readonly`.
- При обращении менеджера каталог автоматически обновляется, если
  прошло 15 минут с успешного чтения (кэш каждого Python-процесса).
  Кнопка принудительно обновляет каталог.
- При сбое доступа **новый расчёт не использует просроченные данные**;
  показывается ошибка, существующие рабочие операции не затрагиваются.
- Для вычисления маршрута нужна **виртуальная палета**
  `Артикул;Количество`. Адреса считываются только по существующим
  привязкам в карте склада. Если адрес/габариты отсутствуют или один
  артикул привязан к нескольким ячейкам, позиция исключается из
  рекомендации с явным указанием причины.
- Нет доступа к другим файлам Google Drive, к API маркетплейсов или
  прав на изменение Google-таблицы.
- Ключ хранить как секрет только на личном сервере, ограничить
  права доступа, включить ротацию и резервирование секретов согласно
  политике инфраструктуры. Не помещать его в GitHub Actions logs,
  исходники или клиентский JavaScript.

### Диагностика

- «Подключение не настроено» — обе переменные ещё не переданы серверу.
- HTTP 403 — таблица не расшарена на адрес аккаунта или API недоступен.
- HTTP 404 — неверный ID / таблица недоступна аккаунту.
- Ошибка колонок — структура вкладки «Габариты» изменилась.

Не используйте производственные задания склада работодателя для тестов
этого модуля. Проверка исключительно виртуальная на синтетических
корзинах/тестовых товарах.
